O que este site recolhe

Este site não usa cookies, não tem contas e não recolhe dados pessoais nem estatísticas de visitas. O teste “Descobre o teu perfume” corre no teu navegador e não guarda nada.

Alojamento

O site está alojado no GitHub Pages (GitHub, Inc.). O alojamento pode registar dados técnicos de ligação, como o endereço IP, para funcionamento e segurança. Consulta a declaração de privacidade do GitHub.

Serviços de terceiros (só carregam se clicares)

TikTok: o vídeo incorporado só é carregado se carregares em “Ver aqui”. Ao fazê-lo, o TikTok pode colocar cookies e tratar dados segundo a sua política.

Comentários (Giscus / GitHub Discussions): só carregam se carregares em “Mostrar comentários”. Para comentar é necessária uma conta GitHub e o comentário fica público, sob a política do GitHub. Podes pedir a remoção de um comentário teu.

Fragrantica: os botões abrem uma pesquisa externa; não partilhamos nada com esse site.

Comunidade

Os comentários são da responsabilidade de quem os publica e podem ser moderados ou removidos, em especial se forem ofensivos, enganosos ou incluírem dados pessoais.
